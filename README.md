Retro Social Network
A React-based social networking application designed to facilitate user interactions, including posting, commenting, and liking content. This project serves as a foundational platform for building and expanding social networking features.

🚀 Features
User Authentication: Secure login and registration system.

Post Creation: Users can create, edit, and delete posts.

Commenting System: Engage with posts through comments.

Like Functionality: Express appreciation for posts.

Responsive Design: Optimized for various device sizes.

🛠️ Technologies Used
Frontend: React, HTML5, CSS3

State Management: Redux

Routing: React Router

HTTP Client: Axios
